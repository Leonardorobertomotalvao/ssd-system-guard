# Atualização v1.0.5

A inicialização automática agora é opcional.

Depois de instalar, o usuário pode marcar ou desmarcar:

> **Iniciar SSD System Guard com o Windows**

Instalações limpas deixam essa opção desligada por padrão. Alterar a opção pode solicitar UAC porque a tarefa agendada executa o Guard com privilégios elevados.
