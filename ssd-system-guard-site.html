● Projeto Open Source para Windows

Proteja seu SSD de sistema com mais controle.

O SSD System Guard é uma ferramenta em PowerShell criada para monitorar atividades importantes no Windows, reduzir downloads indesejados no disco do sistema e avisar quando situações que merecem atenção forem detectadas.

Recursos principais

Uma camada simples de monitoramento para quem quer manter o disco do sistema mais organizado e sob controle.

💾

Proteção do disco do sistema

Ajuda a detectar atividades indesejadas relacionadas a downloads e uso do SSD principal.

🎮

Monitoramento de jogos

Acompanha situações relacionadas a Steam e Epic Games para reduzir instalações no lugar errado.

🔔

Alertas inteligentes

Exibe avisos quando aplicativos ou atividades desconhecidas precisam da sua atenção.

⚙️

Inicialização opcional

Você decide se o SSD System Guard deve iniciar automaticamente junto com o Windows.

🧹

Instalação e remoção simples

O projeto foi pensado para ser fácil de instalar, configurar e remover quando necessário.

🔓

Open Source

O código fica disponível no GitHub para consulta, melhorias, issues e contribuições da comunidade.

Como começar

Baixe, execute e configure conforme a forma que você utiliza os seus discos no Windows.

01. Baixe Acesse a área de Releases no GitHub e obtenha a versão mais recente.
02. Instale Siga as instruções do projeto e permita somente as ações que você compreender.
03. Configure Escolha as opções de monitoramento e se deseja iniciar a ferramenta com o Windows.

Quer testar o SSD System Guard?
